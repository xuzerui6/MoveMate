## 2. A — 峰顶证据重构 + 超幅撤销（`evaluatePeakEvidence`）

每侧周期新增证据采样缓冲：手臂参与（raised>25°、或峰轨迹打开、或已锁存）
的每个测量帧记一条 `{t, raised, elbow, fwd, latDom}`（`latDom` 为
measure() 新增的逐侧横向主导标志：|横向分量| ≥ 前向分量，与前向判定互为
镜像）。缓冲按 4000ms 年龄修剪，任何活动片段的 argmax 样本都远在界内。

片段关闭（`ev.closed.valid`）时按收敛规则裁决（Codex 四约束原文落地）：

- **(a) 同帧联合证据**：样本合格 ⟺ 同一样本内 elbow ≥140° **且** 前向主导。
- **(b) 峰顶绑定**：证据邻域 = 以 argmax 样本为中心、样本 raised 在
  采样最大值 −10° 带内、时间在 ±300ms 内、且由链式间隔连接（见参数表）
  的连续样本段。带外或链断处一律不算峰顶证据。
- **(c) 持续性**：合格需要 ≥2 个联合合格样本且跨度 ≥50ms；单个好帧无论
  多好都不能单独成立，也不能靠插值延长。
- **(d) 可撤销**：argmax 样本本身携带明确反证据（elbow <130° 或横向主导）
  → 直接否决；邻域内出现持续性反证据（≥2 个连续反证据样本、跨度 ≥50ms）
  → 撤销。非峰值的单个反证据样本只作抖动桥接——它单独决定不了任何事；
  一段短弯肘爆发若与关键点毛刺不可区分，按保守处理（不计）。

评分隔离：peakElbow/peakAmp/peakPosture/peakOther 仍取自 `ev.closed` 的
插值极值与 `ev.best` 快照，与第三轮完全一致；四轴公式未动。

**超幅撤销**：可靠片段的插值极值 >115° 时置周期级 `overshoot` 并清掉
已锁存的 peakStart；已置位后同一次举臂的后续片段不再锁存。115° 规则
本身不变（带内第二片段在无超幅时仍只计一次——有对照夹具）。

## 3. 周期保留（软中断）

`interrupt()` 新增可选 `preserveCycle`：保留时 raiseSides、raisePending、
lastPeak 在 `resetCycle()` 后恢复。`softInterrupt` 仅对 front_raise 计算
保留资格：空洞时钟从最后一个测量帧起算，`now − holeStart ≤ 2000ms`
才保留；超时即按旧行为清零，任何非软中断（formInterrupt、会话级
interrupt）也照旧清零并清掉空洞时钟。下一个成功测量帧清掉空洞时钟。

不制造峰值，三重防线都在：`feedPeakTrack` 的 gap 规则在空洞两侧禁用
抛物线精修；证据链在超限间隔处断裂；返回确认的单帧记账上限 100ms 不变。

## 4. 阻塞门提示 + 方向锁存 + 死区文案

`updateFrontRaise` 不再使用 measure() 的双侧聚合 `f.hint`（它要求双臂
同时前向，在正确的单臂举臂全程误报）。新 `frontRaiseBlocker` 取「尚未
锁存峰值的更抬起一侧」为活动侧，按阻塞优先级命名当前真正卡住的门：

1. 超幅（当前 >115° 或本举已置 overshoot）：「举得有点高啦——到肩膀高就好」
2. 中途转侧（方向曾锁存前向、随后持续横向主导）：「刚刚转成侧边啦——前平举要朝正前方抬」
3. 明确弯肘（前向、raised ≥45°、elbow <130°）：「手肘再伸直一点点，整条手臂一起抬」
4. 方向未确认（非前向、未锁存、raised >37°）：沿用原文案「尚未确认前举方向；请向身体前方抬臂，侧平举不计入」
5. 死区（25°<raised≤37°、非前向、未锁存）：「继续抬臂，方向待确认」

死区是构造性的：前向锥要求 dot > 0.6|v|，而 elevation θ 处前向分量上限
是 sinθ；θ ≤ asin(0.6) ≈ 36.87° 时锥在几何上不可能通过——那里的「方向
未确认」不是用户错误，文案只要求继续抬臂（`DIRECTION_DEAD_ZONE_DEG=37`）。

**方向锁存**（逐侧、逐举）：前向 run 持续成立（≥2 样本、跨度 ≥50ms、
间隔 ≤150ms）→ 锁存；持续横向主导 → 解锁存并置 mixed（本举内不可再
锁存）；若锁存过前向又转横向，另置 turned（提示第 2 级）。锁存只供提示
历史，**永不替代峰顶时刻的前向证据**（§2 (a) 仍逐样本重判）。锁存/mixed
随周期替换（确认返回或硬重置）清除——即可靠追踪丢失。注意低帧率下
（间隔 >150ms）锁存不累积、保持惰性，提示回落到逐帧门判断，不影响计数。

## 5. C-lite 取景信号

measure() 对 front_raise 新增 `framing`：人脸边距比
|face| / (肩–骨盆距 × 0.06)——即签署前向轴的鼻尖信号强度，以既有的拒绝
阈值为单位。比值 <1 就是 measure() 返回错误串的**无法确认**态（经
formInterrupt 浮现，行为不变）；1–2 为**不足**；≥2 为**满足**。

起始保持）一字未动**，信号也从不断言该角度「测得准」——它只能说前提

## 6. 不对称插桩（仅诊断）

回放驱动新增转储逐侧 latDom 与周期状态（overshoot/锁存/证据样本），并在
同一输入上新旧同跑（见 §8）。raised≥65° 帧的逐侧分布（新旧通道相同）：

- 逐片段峰值（双侧片段）：#1 右 170.4° vs 左 122.9°；#2 162.5 vs 126.1；
  #3 146.6 vs 119.0；#4 98.5 vs **104.3（左更高）**；#7+8 右 119.8 vs
  左 106.9；#9 166.0 vs 160.5。
- 配对帧（左在带内，n=37）：右−左差中位 **+3.6°**、均值 +9.3°、最大 +52.5°。
- 肘通道同样不对称：raised≥65° 帧肘中位左 123° / 右 146°，≥140° 占比
  左 0.16 / 右 0.57。

**结论：不是恒定偏置，是逐片段发作型深度噪声**——中位差很小、均值与极值
被少数片段拉大，且存在左高右低的反例片段。这与锤式回放的结论同型（逐次
发作、符号翻转的深度噪声，而非常量偏置）。代码层检查：measure() 的
raised 与 elbow 计算对两侧完全对称（同一组共享轴、同一 `[0,1].map`），
不存在逐侧变换差异。**未发现明确代码 bug，本轮不修**；后续若处理，应
走评分聚合层（如集合级中位数）或测量层正交化（Codex 路线 B），另行
立项，不在识别门里打补丁。
