## 页面与交互

动作库支持图文列表、图片／动态／摄像头独立标识、“有示范”筛选；肌群、器械、收藏等选项折叠到更多筛选。筛选使用既有 `ids` 参数在服务端分页之前生效，和搜索、收藏及摄像头条件取交集。当前白名单小于接口 500-ID 上限，测试会在扩容超限前阻止发布。

详情提供动态、分解和肌群三种视图。视频须主动点击，默认静音，支持暂停、重播、倍速、原生进度条和放大弹窗；列表不加载视频。所有图片与视频按原比例完整显示，无 CSS 裁切。素材许可独立于动作文字来源，在详情内可查看作者、许可及完整清单。

计划编辑器、自由训练选动作、计划记组准备及独立 AI 准备复用相同组件。在准备页展开示范不会启动任何设备；开始／恢复本组时暂停示范，识别器和摄像头引用不变。切组、切视图、关闭弹窗及离开页面会暂停并卸载对应视频源。多播放器互斥只管理示范播放器，不遍历或暂停摄像头。

弹窗沿用现有焦点锁定和 Escape 返回机制；示范标签支持方向键／Home／End，触控操作至少 44px。无自动播放，减少动态效果设置不会触发动画。

## 来源与核验

### 图片

来源：[free-exercise-db](https://github.com/yuhonas/free-exercise-db)，固定提交 `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`，按来源仓库公开的 Unlicense 声明采用。原图未逐张署名，保留这一事实，不将上传者虚构为摄影作者。原始许可位于 `/exercise-media/UNLICENSE.txt`。

使用固定版本元数据和原始 SHA-256 验证后转为 WebP，按比例缩小，不裁切或改绘人物。每对照片逐项查看，核对器械、姿势、握法及单／双侧；不根据关键词给近似变式配图。

### 视频

来源：wger 视频 API 的 6、12、17、71 号条目；作者均为 **Goulart**，条目标明 **CC BY-SA 4.0**。原始 URL、字节 SHA-256、采用片段、作者和许可保存在白名单及发布清单。去除音轨，按原比例转为 H.264/MP4，提取封面；衍生视频与封面继续采用 CC BY-SA 4.0，完整许可另在 `/exercise-media/CC-BY-SA-4.0.txt` 提供。

逐时间段查看了起始、发力及回落画面。6 号仅采用 6–11.2 秒的双臂侧平举，剔除后续前平举；12 号采用 2–16 秒，17 号采用 0–14 秒，71 号采用 0–10 秒。其余候选未自动发布。

明确剔除：名义杠铃硬拉而画面为哑铃的视频、旋转握法弯举、取景不佳的卧推、器械台阶提踵、交叉后撤弓步。双脚平地提踵和普通后撤弓步没有用这些变式顶替。

肌群图复用已有 MuscleMap MIT 几何数据，保留许可入口。未取用 [openGym 受限媒体](https://github.com/DuarteSantos8/openGym/blob/main/NOTICE.md)，也未用其图片作为生成输入。本批没有新增 AI 原创人体示意，缺项后续逐条取得适用素材或完成原创动作审核后再发布。

素材检查是来源、变式和可见动作过程核对，不构成专业动作认证。新增摄像头动作的真人识别质量仍按既有“试用”状态处理。

## 运行与扩充

常规构建直接使用已提交的发布文件，不访问素材上游。扩充时先在项目外准备候选文件，逐项审核并更新白名单，再用开发工具生成；不得跳过源字节核验。

```powershell
# 仅素材维护需要 Python、Pillow、imageio-ffmpeg；不是运行站点的依赖。
python scripts/build-exercise-media.py --staging C:/outside/staging
node --import ./server/node_modules/tsx/dist/loader.mjs scripts/report-exercise-media.ts
npm test --prefix client
```

`staging/candidates/` 存放 `<sourceId>-0.jpg`、`<sourceId>-1.jpg` 和 `wger-<id>.mov`；原始文件、临时抽帧与 QA 脚本不进入 Git。未核对的候选不会进入 manifest。

静态文件名含内容哈希。Worker 对视频提供单段 Range、尾段、开放尾段和 416 响应；不支持的多段请求按 HTTP 规则返回完整表示。缺失媒体返回 404，不把 SPA HTML 当作视频缓存。Service Worker 只缓存浏览过的哈希图片，明确跳过视频和 Range 请求；视频不默认离线缓存。已有缓存图片和账号只读内容可用于离线查看，未缓存示范给出失败与重试提示。

无需接口新增、数据库变更或迁移。媒体按 ID 独立查表，不写入训练快照，不改变识别映射、计时、XP、装备及组局结算。
