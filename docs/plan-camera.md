# 动作库摄像头记组 · 2026-10-18

2026-10-30 更新：另新增锤式弯举、前平举、俯身臂屈伸、罗马尼亚硬拉、地面臀桥和后屈腿，同时支持独立训练、计划及自由训练。当前共有 20 个指定摄像头条目，见[新增六种 AI 动作](recognition-six-actions.md)。以下六类仍仅在计划及自由训练开放，原规则保留。

## 如何使用

进入训练 → 动作库，勾选“支持摄像头”。加入计划或自由训练后，在对应次数组点击“摄像头自动记组”。先按页面说明摆放摄像头并保持起始姿势两秒，完成目标后自动进入休息；休息结束手动开始下一组。

原深蹲、开合跳、高抬腿和俯卧撑继续可用。新识别标为“试用”，仅在计划及自由训练开放，不进入独立 AI 训练的按次数奖励接口。

| 新识别 | 明确允许的动作 ID | 摆放与计数 |
|---|---|---|
| 站姿双臂弯举 | exdb:0294、exdb:0416 | 正面略侧身；同时弯举、放回为一次 |
| 双臂侧平举 | exdb:0334 | 正面，双手侧举仍入镜；侧举、放回为一次 |
| 坐姿双臂肩推 | exdb:0405 | 正面略侧身，头顶双手入镜；推起、放回为一次 |
| 双臂俯身划船 | exdb:0293 | 斜侧面；俯身拉起、放回为一次 |
| 交替后撤弓步 | movemate:reverse_lunge | 斜侧面全身、脚尖方向可见；每侧后撤下沉、回到站立为一次，显示左右次数 |
| 平地双脚提踵 | exdb:1373 | 斜侧面全身，脚跟与前脚掌可见；双脚提踵、落回为一次 |

本页六类对应七个动作库条目，加原四种为最初 11 个条目；新批次增加九个指定条目。后撤弓步是动伴独立文字条目，没有将前弓步或行走弓步改名。单臂、交替弯举、单腿提踵、台阶提踵、其他器械变式、计时组和单侧目标组继续手动记录。

## 识别、评分与数据边界

- 新动作采用独立计划识别状态机，五帧中值平滑、两秒校准、峰值与回位确认；使用视频实际比例及身体尺度，可靠时使用三维关节角。原四种识别器的阈值和状态机不变。
- 评分按幅度 35%、稳定控制 25%、身体姿态 20%、协调 20% 加权；页面显示最近一次评分及均分、四维累计均分。评分不充当计数门槛。完成动作但置信度不足时保留次数、不生成评分。
- 暂停、持续遮挡、画面中断与刷新丢弃半程；完成次数、评分累计及弓步左右次数保存到现有组 JSON。零次评分的左右记录也能恢复，不以次数推造评分。
- 计划按完整有效运动分钟结算 XP，休息与暂停不计时；新动作不另建运动记录、不按次数重复奖励。摄像头不能读取哑铃重量，重量由本人填写。
- 动作库可选 `planCamera` 描述及 `camera=1` 筛选。能力按服务端明确 ID 白名单分配；导入、自定义名称和客户端传入的能力字段不能授权识别。开始训练时取得能力快照，已有训练不自动升级。
- 训练与语音使用本组实际名称、目标和阶段。关键点仅在页面内存使用；没有新增图像、音视频或关键点上传。可选语音关键帧复核沿用已有单独授权。
- 无数据库迁移，无付费服务。回滚只回滚代码，保留已有账号、记录及 XP。

## 验收

- 客户端 100、后端 65、Workers 原生运行时 26 项测试通过，共 191 项。新增覆盖六类完整动作、半程、静止抖动、短暂置信度波动、遮挡、5/15/30 FPS、横竖画面比例、暂停和恢复、无评分次数、左右计数、标准 ID 白名单、未知变式与自定义能力拒绝、账号隔离、重复结束及一分钟仅 1 XP。原四种识别回归通过。
- 本机隔离浏览器回放：动作库筛选得到 11 个条目；六个标准动作各自动记录 2 次并进入休息，后撤弓步左右各 1 次。暂停后刷新恢复第六组，前五组记录保留；最终服务端确认 6 组、54 秒、0 XP，逐组历史可读取次数、均分、四维均分及左右记录。
- 权限拒绝与模型加载失败模拟均未开始本组计时；模型失败后摄像头解除挂载，重试成功。结束并离开训练后页面无视频元素，相关控制台无错误。
- 390、768、1440px 页面检查无横向溢出。检查时发现高帧率调度可能放大瞬时速度，已改为至少 100ms 的测量窗口，后续肩推、划船、弓步、提踵回放及相关回归使用修复后的实现。
- Browser plugin 不可用，浏览器验收使用 CUA 提供的 Playwright 接口。回放由项目外临时服务提供，仅作用于隔离本机地址，没有把摄像头模拟、测试账号或测试接口部署到正式站。

真人动作质量、实际哑铃使用、真实手机光线与遮挡情况尚待专项校准；试用标记不代表实拍验收通过。本轮没有重新进行真人有声或 BLE 验收。
