# 统一语音陪练

Cloudflare 使用一个专用小智运动陪练智能体，可在同一智能体下绑定多台设备。本站最多保留 5 个设备位；设备同时只供一个动伴账号使用，一个账号同时只占一路。五路是实现上限，实际容量取决于当前已绑定、通过隔离验证的设备和上游免费额度。

## 配置与启用

1. 使用管理员账号访问 `/admin` →「语音服务」。普通账号不能读取或修改该面板的接口。
2. 通过 Cloudflare Secret 配置独立、至少 32 字符的 `XIAOZHI_POOL_SECRET`，生产与预览各用不同密钥。设备身份使用 AES-256-GCM 加密，附带设备位关联校验；不要直接轮换后丢弃旧密钥，否则已有设备需重新绑定。原 JWT 等 Secret 保持不变。
3. Cloudflare 的 `XIAOZHI_IDENTITY_MODE=shared` 启用设备池适配，公开服务默认关闭。生成前两个设备激活码，在小智官方控制台绑定到**同一个专用运动智能体**。无须向本站提供小智账号密码。不要使用日常私人助手。
4. 小智配置关闭记忆、私人 MCP 工具、私人知识库及其他历史会话继承。每次分配会建立独立上游连接，不传入先前使用者的上下文；这不能替代对上游实际记忆行为的验证。
5. 检查当前账号免费额度及接入许可。2026-10-15 实际控制台的「设备接入协议」显示：免费开源版仅限学习，禁止商业、生产或盈利场景；正式版在该账号下不可用。不能据此向正式站所有用户开放。接受协议须由账号所有者明确确认；仅获准学习演示时，只对指定验证账号测试，公开开关继续关闭。公开资料未提供本站可保证的五路免费并发承诺；不得因为本站有五个设备位就宣称上游保证五路。遇到收费、升级或额度限制时停止，不绕过。
6. 点击「检查绑定」，启用待验证设备。公开开关保持关闭，在「验证账号」填入最多五个真实用户 ID。只有这些账号可提前使用待验证设备；管理员还可通过指定设备测试入口检查单个设备。
7. 两个未做个人绑定的普通账号同时训练，分别开启语音；检查各自听说、互不打断。再让不同账号先后使用同一设备，使用非个人的测试短语检查是否跨用户继承。关闭语音、退出训练、退出账号及切换账号均须释放。未验证的设备不能标为已隔离。
8. 仅在接入许可允许对真实用户提供服务、且设备隔离验证通过时，才勾选通过验证的设备并打开公开服务。当前免费学习演示许可不满足公开条件，保持关闭。仅正常绑定、启用且验证完成的设备会分配给普通用户。忙碌时显示稍后重试，训练仍可使用本地文字反馈。

本机默认个人模式继续使用既有个人绑定流程；云端普通用户不显示激活码，也不跳转小智账号。进入训练不申请名额，用户点击「开启语音陪练」才申请。

## 接口与会话生命周期

- 管理：`GET/PATCH /api/v1/admin/voice`、`POST /devices/:slot/create|activate`、`PATCH/DELETE /devices/:slot`，后几个路径均相对 `/api/v1/admin/voice`。每次校验 JWT 和当前数据库管理员角色。管理员列表不会返回设备密钥或上游令牌；激活码只返回管理员。
- 使用：`POST /api/xiaozhi/device` 接收每页随机 `clientId`，分配后签发 HttpOnly、Secure、SameSite=Lax 的账号和租约 Cookie。`testSlot` 仅当前数据库管理员可用。
- `/api/xiaozhi/socket` 同时校验账号、同源请求、签名 Cookie、设备状态和单次租约；同一待连接租约只能认领一次。普通个人设备 Cookie 不能用于共享设备池。
- 前端每 15 秒发送桥接心跳，服务端将租约延长至 45 秒。用户开始对话、上游识别或语音播放更新活动时间；心跳本身不更新活动时间。连续两分钟无对话和播放则关闭，要求手动重新开启。
- `POST /api/xiaozhi/release` 必须携带所属账号、签名 Cookie 和对应 `leaseId`。关闭事件另外比较连接 ID，旧请求和旧关闭回调不能删除新租约。
- 释放上下游连接后才回收设备。断线、过期和进程重新建立使用 Alarm 回收；不能确认上游正常关闭时隔离设备并显示异常，不把可疑连接直接转交下一用户。
- 设备、租约分别保存在 `voice_devices`、`voice_leases`；设置保存在 `actor_meta`。增量建表不改变账号、活动、训练和 XP。分配与生命周期更新复用事务队列；设备身份只在服务端解密使用。
- 本站不保存完整音频、图片和陪练对话。仅保留不含内容及凭据的连接阶段诊断，逐用户关键帧授权维持原行为。

## 验证

`npm test --prefix cloudflare` 在真实 Workers 模拟运行时验证：五路独占、第六路忙碌、同账号多页、独立上游会话、二进制传输、错误凭据／来源、单次认领、旧关闭回调竞争、设备停用、45 秒过期、两分钟空闲、进程代际隔离、验证账号限制及密钥不返回。模拟上游不代表真实小智的记忆隔离或五路实音通过。

后端原 32 项与客户端原 22 项回归保留，另新增 3 项麦克风生命周期测试及 3 项跨标签页会话一致性测试；Workers 共 22 项（含父测试），合计 82 项。麦克风测试覆盖权限申请未完成就关闭、Worklet 加载中退出及重复唤醒，保证迟到的媒体流也会停止，不在关闭后重新捕获。预览站验收后台 390／768／1440px、五个设备位、无横向溢出或相关页面异常；普通账号训练验证不自动申请设备、点击才连接、未开放时显示真实原因且不出现个人激活入口、语音关闭后仍可暂停和结束训练。截图与临时脚本保存在项目外。

公开开关和设备验证状态保存在数据库，重新部署不会自动打开服务。回滚代码保持数据库不动；已经开放写入后不得恢复旧 Turso 快照。

两路真实上游连接曾同时完成握手并获得不同会话 ID；直接发送协议文本未取得完整语音回复，上游随后断开，该尝试不算有声或跨用户隔离通过。2026-10-16 恢复两个普通成员账号的浏览器验收，软件内置浏览器已显示上游 TTS 回复；用户随后明确回复“两个窗口都能听到”，因此两路同时有声通过。未保存录音或完整对话。

当前**两路真实同时有声已获用户确认**；前后账号复用同一设备的口令隔离检查由用户反馈“未完成或无法判断”，仍为待验收，五路免费并发容量未作真实验收。此前个人模式的有声确认不能代替设备池验收。五路模拟并发已通过，不宣称五路实音通过。免费条款不允许的正式运营始终不开放。

多标签页会话同步：同一浏览器任意页面退出或切换账号后，其余页面同步清理旧账号内存状态，由既有组件卸载流程关闭语音、设备和实时连接。分两次写入的 token／资料只有账号归属一致才会恢复，避免短暂混用两个账号。服务端仍独立验证 JWT 签名及权限。

多标签页退出与切换账号已分别在预览和生产真实浏览器中验证，普通账号无法保留旧管理员界面；关闭两路语音后，管理接口确认两个租约均已释放。
