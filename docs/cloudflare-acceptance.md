## 性能与网络限制

早期 Meta/TUN 路由下，同一测试脚本各五轮冷／热访问的中位数如下，仅为观察值：

| 指标（毫秒） | 原 Vercel | Cloudflare |
|---|---:|---:|
| 冷访问首页可见 | 2521 | 1520 |
| 热访问首页可见 | 1870 | 1113 |
| 冷访问普通接口 | 525 | 869 |
| 热访问普通接口 | 500 | 466 |

首页观察值更快，冷接口更慢，不能宣称所有访问均改善。用户随后关闭 TUN，核对默认路由仅为 WLAN，DNS 返回真实 Cloudflare IP。直连浏览器登录等待 45 秒超时，未取得合格的五轮同条件业务对比；两个 IP 的独立 HTTPS 健康请求虽返回 200，总耗时约 8.0 秒与 5.1 秒，其中 TLS 握手约 7.5 秒与 4.4 秒。代理控制请求健康接口 200、约 0.8 秒。

随后使用正常登录会话在无代理浏览器重新访问首页，仍出现 60 秒页面导航超时，不能提供合格的五轮结果。因此，**当前 WLAN 的无代理访问速度与稳定性验收未通过**。迁移与功能通过不代表该网络条件通过。没有为测速解除源库冻结，也没有添加第三方优选 IP、关闭证书校验或升级付费网络。
