# AI 动作计数修复 · 2026-10-17

## 已定位与修改

四种动作共用的识别器在五帧平滑之前就拒绝轻微低置信度帧，导致校准和半程动作反复清空。独立回放中四种动作均可复现“应计三次、实际零次”。

- 先平滑轻微抖动，再判定动作；人体丢失、严重遮挡、持续低置信度及画面长时间中断仍丢弃半程动作，不补计。
- 俯卧撑在单次动作内固定跟踪清晰的一侧；四种动作的角度阈值、150ms 阶段确认和原奖励规则保持不变。
- 独立训练与计划记组共用修复。增加对应动作阶段、未计数提示和高抬腿左右配对状态。
- 默认收起的本机诊断显示帧率、置信度、角度、跟踪侧与最近重置原因；诊断对象与持久化训练统计分开，不上传或保存关键点。
- 摄像头循环检测长时间未更新的画面，清除旧关键点；暂停、恢复和刷新保留已完成次数并重新校准。
