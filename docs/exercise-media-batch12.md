## 逐条说明

- **exdb:0124 杠铃宽站距深蹲**：来源步骤为双脚分开比肩宽、脚趾微向外、杠置上背、下蹲至大腿平行。正视 3 帧：宽站距站立、上背杠下蹲（下箭头）、脚跟推地站起。正视站距是与已图解高杠深蹲（exdb:1436）的区分点。注：来源同时允许斜方肌与后束托杠，本批按上背杠绘制，不作高低杠区分宣称。
- **exdb:0091 杠铃坐姿过顶推举**：来源步骤为坐凳、双脚平放、正手握杠略宽于肩置于肩高、推过头顶。坐姿正视 3 帧：坐稳杠置肩高、双臂伸展推过头顶（上箭头）、控制下放回肩高；坐姿直杠，与站姿双哑铃推举（exdb:0426）可区分。
- **exdb:0319 哑铃上斜飞鸟**：来源步骤为 45 度上斜凳、中立握、双铃弧线展开。侧视 3 帧：上斜靠背、双铃胸前上方、宽弧线向两侧放低（外展箭头）、挤压胸部拉回。斜凳以 support 斜线绘制，沿用 exdb:0315 的上斜凳画法。
- **exdb:0302 哑铃下斜飞鸟**：来源步骤为下斜凳、双脚固定、头部低于臀部、中立握弧线展开。侧视 3 帧：下斜躺姿、双脚勾住凳端固定垫、双铃胸前上方、宽弧线向两侧放低、挤压胸部拉回；凳面下斜方向与 0319 相反。注：第一版把双脚画到地面，被自检驳回后改画为勾住凳端固定垫。
- **exdb:0049 杠铃上斜胸托划船**：来源步骤为 45 度上斜凳俯卧、胸部靠垫、双脚平放、正手握杠拉向胸部。侧视 3 帧：俯卧胸托、杠悬于胸前下方、拉向胸部挤压肩胛（上箭头）、控制下放；胸托支撑，与站姿俯身划船不同。
- **exdb:0092 杠铃坐姿过顶臂屈伸**：来源步骤为坐凳、正手握直杠与肩同宽举过头顶、屈肘降杠至脑后。坐姿侧视 3 帧：直杠过顶、屈肘降杠至脑后（脑后位置在头后方，不与面部重叠；第一版杠画在面前被自检驳回后改到头后）、伸展回过顶；坐姿直杠，与站姿单哑铃过顶臂屈伸可区分。
- **exdb:0070 杠铃牧师凳弯举**：来源步骤为坐牧师凳、上臂托垫、反手握杠略宽于肩、屈肘至肩前。坐姿侧视 3 帧：上臂贴斜托垫、杠下垂、屈肘弯举至肩前（上箭头）、控制伸肘回位。注：第一版托垫斜线与手臂线重合、垫面不可见，被自检驳回后把垫面移到手臂线右侧并补垫腿，垫面与手臂形成可读的贴合角。
- **exdb:0123 杠铃宽握直立划船**：来源步骤为正手宽握（握距大于肩宽）、杠垂腿前、屈肘提至下巴、肘引导。正视 3 帧：宽握杠垂腿前、屈肘提杠至下巴且肘高于手（上箭头）、控制下放。注：第一版杠只提到胸前，被自检驳回后改到下巴高度、肘高于手；与版本 2／版本 3 文本近同，本批只按自身宽握步骤绘制，不作版本对比宣称。
