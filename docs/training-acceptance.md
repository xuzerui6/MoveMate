# 训练流程重设计与修复验收

日期：2026-10-16，最终发布核对：2026-10-17。视觉方向由用户选择第一张「画面优先」。设计约定见 [training-design.md](training-design.md)，对照记录见 [design-qa.md](../design-qa.md)。

## 实现

- 训练入口改为并列方式切换，移除重复运动选择器；准备页压缩为动作要求、明确视觉范围、开始／演示，心率设备折叠。
- 训练主屏采用画面、次数／有效时长／评分、单条提示、统一语音入口。手机等宽操作固定在导航上方，平板紧凑侧栏，电脑画面／数据分栏。延续字体、白绿变量、像素素材和Phosphor。
- 新训练先准备相机和模型，再创建记录。晚到流或模型由可取消资源作用域释放；失败不创建新记录。恢复时也能直接结束已有记录，无需再次取得相机权限。
- 动作中断和结束快照立即冻结，传输按账号队列串行；待发进度合并，控制操作作为顺序屏障。结果不明先查询，再决定是否重试；保留原幂等结算。
- 进度使用返回记录更新局部状态，不逐次读取全部历史；服务端快照校准墙钟，后台停顿不靠逐秒累加。旧读请求不能覆盖新写记录，切换账号阻止旧队列发起请求。
- 相机与计时使用统一结算样式。结算成功与成长读取分开，读取失败单独重试。恢复保留评分累计值、纠错和陪练轮数；退出／结束释放摄像头、模型、语音与心率连接。
- 未新增接口或数据库迁移，不改XP、装备条件、权限、组局及共享语音池设置。
