## 页面与响应式

| 页面 | 主要内容 | 主操作与异常 |
| --- | --- | --- |
| 入口 | 标题、未结束记录、并列的动作训练／个人计时方式；仅展示所选方式的运动选择 | 四种动作或一个运动下拉；开始操作首屏可达 |
| 准备 | 紧凑动作说明、每组目标、明确视觉授权；心率设置折叠 | 开启摄像头并开始／演示；准备中可取消，失败就地重试 |
| 训练 | 单一标题、画面、次数／时长／评分、单条纠错、语音入口 | 手机底部固定暂停与结束，位于导航上方；电脑画面与信息分栏 |
| 暂停 | 画面覆盖「已暂停」、保留已完成次数 | 继续需重新校准；不显示校准中或纠错信息 |
| 恢复 | 原动作、来源、次数、服务端时长 | 不允许改动作或来源；摄像头就绪后才恢复记录 |
| 异常 | 原内容与数字保留，错误附于相关区域 | 暂停／结束结果不明时冻结识别并查询服务端，支持重试 |
| 结算 | 已保存、运动量、服务器确认 XP、演示标识 | 成长更新失败单独重试；详细评分与心率按需展开 |

## 行为约定

- 图中运动照片仅为相机取景示意，产品实际使用实时视频或明确标记的演示骨架，不把示例照片当作训练数据。
- 进入页面不请求设备。实际开始前完成相机及模型准备，成功后才创建／恢复服务端运动；取消与失败释放异步返回的资源。
- 暂停、离开、结束即时中断动作状态机；结束冻结同一份统计快照。响应丢失先读取既有记录，确认已完成时直接显示结果。
- 进度与控制操作逐记录串行；等待中的进度合并为最新完整快照。时间由服务端快照加墙钟差显示，不通过定时器累计。
- 单组目标20，达标提示结束，不自动结算。演示0 XP，实际动作2 XP／次或组。语音按需手动连接，退出释放，保留个人模式与共享池。
- 不增加接口、迁移数据库或改变权限、装备、组局和奖励规则。

## 验收

覆盖四动作演示、关键点回放、暂停丢弃半程、权限及模型失败、异步设备取消、结束响应丢失、进度顺序、刷新恢复、账号隔离及390／768／1440布局。真实摄像头质量与真人有声记录独立报告。
