# 锤式弯举对称小轮：对侧峰值记忆跨软中断保留 + 集合对称中位数聚合（2026-11-08）

真机证据（Edward 2026-11-08 16:49 锤式弯举双臂组：计数 14、组分 71、四轴
87 / 53 / 97 / **41**；离线回放诊断
`~/workspace/movemate-research/hammer-replay-2026-11-08.md`）：第三轮的稳定性
持续聚合已见效（38 → 53），但双臂协调 41 基本没动。回放把成因钉成两条叠加
的低分路径：

- **(a) 主因 — 拆开评分 + 瞬时公式**：双侧努力被拆成单侧发出时，第三轮的
  峰对峰救济多数场合不触发——`peerPeakFor` 的第一数据源 `lastPeak` 在每次
  interrupt 时被 `resetCycle()` 一并清零，第二数据源要求对侧在发出瞬间已
  锁峰，常不满足。落入瞬时公式后，同步举的对侧正处行程中段（peakOther
  实测 87–98°）→ 对称 37–50。全管线回放唯一一条完整幸存的评分 Rep 正是
  此形态（对称 37，与真机同档）。
- **(b) 辅因 — 大 Δ + 均值聚合**：合并/峰对峰成立时双侧峰值肘角差实测
  25–43°（对称 35–63）；通道差不是恒定偏置，而是逐次发作、变号的深度
  读数噪声。集合对称取逐次**均值**，一次被噪声击中的 Rep 即可拖垮全组。
  Edward 已拍板（2026-11-08）：集合级双臂协调改**中位数**。

本轮只动这两处，冻结清单见 §5。

## 2. 对侧峰值记忆保留（`peerPeakSnapshot` + `preservePeerPeak`）

`interrupt()` 新增可选 `preservePeerPeak`（与第四轮 `preserveCycle` 并列）：
保留时，先用 `peerPeakSnapshot()` 在 `resetCycle()` 之前快照对侧峰值记忆，
重置后写回 `lastPeak`。快照构成（逐侧取最新者）：

1. 已完成记录 `lastPeak[s]`（完成时写入的峰中点 + 峰值）；
2. 打开周期里**已锁定的峰**（`peakStart` 已由有效闭合片段设定、但尚未完成
   回位确认的那一峰）——折为与完成记录完全相同的形态 `{at: 峰窗中点,
   value: peakElbow}`。这正是诊断所指「峰从未『锁定』进 lastPeak，只因被
   中断」的情形：它在周期里已经锁定，缺的只是完成；
3. 仍打开着的峰片段的**最深样本**——仅当其在区驻留（以最后测量帧计）已
   达到闭合片段必须达到的同一驻留地板 `PEAK_MIN_DWELL_MS`（25 ms）时才
   采信，记 `{at: bestAt, value: 80 − track.best}`（锤式深度信号为
   80 − 肘角；片段未闭合，插值精修不可知，采样极值是诚实记录）。

`softInterrupt` 对 `hammer_curl` 计算保留资格，与第四轮前平举共用同一
空洞时钟与同一界 `CYCLE_PRESERVE_MS = 2000`：空洞自最后测量帧起算，
≤2000 ms 保留，超时即按旧行为清零。**界的依据**：第四轮前平举周期保留
已取此界；自适应包装层对锤式的证据冻结宽限 `HAMMER_FREEZE_GRACE_MS`
同为 2000 ms——两层对「空洞多久算长」口径一致；前平举回放的致命空洞
实测 ≈0.8 s，界须显著大于它又远小于「用户离场」尺度。

不变的边界：

- 周期本体与 `hammerPending` **不保留**——空洞后不可能凭空造出一次计数，
  与修复前一致；
- `formInterrupt`（形态拒绝）、会话级 `interrupt()`（暂停/结束、包装层
  硬中断）照旧清零记忆；组结束即新 tracker，记忆不跨组；
- `peerPeakFor` 本体与其 800 ms 窗口一字未动——花掉记忆时仍逐次核对
  `|at − 本侧峰中点| ≤ PEAK_PAIR_WINDOW_MS`，快照不可能把时间上不接近的
  两个峰配成一对；合并窗 150 ms、pending 600 ms、逐次三分支公式
  （合并/峰对峰 `100 − |Δ| × 1.5`、瞬时 `100 − max(0, 140 − peakOther) × 1.2`）
  全部未动。

## 3. 集合对称中位数（`medianOf` + `symmetryValues`）

- 定义：逐次对称值排序后取中位——奇数个取正中值，偶数个取中间两值均值
  （`sessionMigration.medianOf`，与既有 `sustainedPeak` 同为可测纯函数）。
- 记录点：仅 `emitHammerRep` 在评分成立时把本次 `breakdown.symmetry`
  追加进累计器 `scoreAccumulator.symmetryValues`（新数组，不原地改）。
  这是唯一记录点，也是中位数只作用于锤式弯举的落点——前平举与通用路径
  的累计器永不带此字段，`updateAverage()` 对它们继续取均值。
- `updateAverage()`：有记录值时集合对称 = 记录值的中位数（四舍五入）；
  深度/稳定性/躯干仍为均值；总分权重 .35/.25/.20/.20 与 `formScore`
  （逐次总分均值）未动。`symmetry` 累计和仍同步维护，作为无记录值时
  （旧版本恢复的组）的均值回退。
- 历史已存组的分数**不重算**：历史记录里存的是当时产出的 formBreakdown，
  原样保留（见 §4）。
