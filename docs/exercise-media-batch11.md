## 逐条说明

- **exdb:0852 负重深蹲**：来源步骤清楚（双脚与肩同宽、重物胸前或肩上、下蹲至大腿平行）。图解取来源允许的胸前持重形式：壶铃抱于胸前，3 帧为站立抱铃、下蹲至大腿平行（下箭头）、脚跟推地站起。
- **exdb:0116 杠铃直腿硬拉**：来源步骤为髋铰链下放、背挺直、膝微屈。按来源步骤取 stiff-leg 定义（膝微屈、不锁死），不画完全锁膝；3 帧为站立正手握杠（握距略宽于肩）、下放至小腿高度（下箭头）、伸髋站起。与已图解的相扑硬拉（宽站距）与双哑铃硬拉（哑铃）均可区分。
- **exdb:0078 杠铃后撤弓步**：来源步骤为上背负杠、一脚后撤、前腿大腿平行。侧视 3 帧：站立负杠、后撤弓步（后脚脚掌着地、前腿平行，下箭头）、推回站立。注：与 exdb:0077（版本2）文本相同、变式区别未确认，本批只按本条目自身步骤绘制，不作版本对比宣称。
- **exdb:1410 杠铃侧弓步**：来源步骤为上背负杠、一脚侧跨、对侧腿伸直。侧视 3 帧：站立负杠、侧跨下沉（横向箭头标示侧移方向）、推回站立；与 0078 的前后分腿方向不同。
- **exdb:0360 哑铃单臂肩推（版本2）**：来源步骤为站姿单手正握（掌心向前）肩高推举。3 帧为单铃肩高（另一手下垂）、推过头顶（上箭头）、下放回肩高；与已图解的坐姿交替肩推（坐姿、双铃）可区分。注：「版本2」与其它单臂肩推的版本区别无独立证据，本批不作版本对比宣称。
- **exdb:3665 上下转换平板支撑**：来源步骤为高平板、逐臂落前臂、再推回高平板。侧视 3 帧：高平板、前臂平板（前臂贴地、下箭头）、推回高平板。注：来源未指定回推先手，本批按左右交替定义并写入文字。
- **exdb:3640 对侧触膝卷腹**：来源步骤指定右手触左膝、左手触右膝、左右交替。仰卧 3 帧：屈膝双手脑后、卷起一手伸向对侧膝（箭头指向膝）、回落换侧。
- **exdb:0456 屈膝收腿仰卧起坐**：来源步骤为卷起至 45 度同时双膝收向胸。仰卧 3 帧：屈膝双手脑后、卷起并双膝离地收胸（上箭头标示收腿）、缓慢放回；与 3640 的单侧触膝轨迹不同。
