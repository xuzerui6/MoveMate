## 构建与页面修复

- 新增 26 张 Unlicense WebP 随仓库分发；新增 10 个站内专用文件仍保存在 `MOVEMATE_MEDIA_DIR/exercise-media/`，不提交 Git。
- 本机、开发与 Cloudflare 构建继续共用既有校验与复制流程，当前 **117 个媒体文件**校验通过。缺失或校验不符会停止构建，不自动下载上游素材。
- `build-exercise-media.py --only` 支持按已审核 ID 增量生成，未选中的已发布条目保持原样。为既有动作附加视频需显式 `attachToExisting`，保留旧图片，并按真实来源索引标记新帧；重复执行相同附件不会复制帧或替换其他视频。
- 浏览器复现了搜索延迟期间点击旧结果，示范随后被新结果收起的问题。现在输入尚未同步、或结果仍在加载时，旧列表的查看、收藏和加入操作暂不可点击；搜索完成后正常恢复。
- 分解、视频和肌群继续复用共享组件；没有重新设计电脑摄像头区域。

增量素材生成示例（开发用，完整网页构建无需执行此步）：

```powershell
python scripts/build-exercise-media.py --staging D:/reviewed-candidates --only exdb:0042,exdb:1409
```

候选目录必须提供清单中 SHA-256 对应的原文件及许可文本。运行所需 Python/Pillow、imageio-ffmpeg 沿用现有开发工具；网页运行不依赖这些处理工具。正常构建配置见 [开发指南](development.md#动作示范素材)。
