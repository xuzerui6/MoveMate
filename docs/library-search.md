# 动作库搜索（拼音 / 俗称 / 部位 / 排序）

搜索实现在 `server/src/gym/search.ts`，由 `service.ts` 的 `library()` 在
非查询过滤之后调用：带查询词时对条目打分并按相关性降序返回，无查询时
浏览顺序与旧行为完全一致。

## 匹配通道（取最高分，再叠加权）

| 通道 | 分值 | 说明 |
| --- | --- | --- |
| 名称（中文/英文） | 相等 100 / 开头 85 / 包含 65 | |
| 别名 | 相等 70 / 开头 60 / 包含 55 | 含 model.ts 合成的别名（原名、英文名、术语组合等） |
| 俗称扩展 | 58 | 见下表；扩展词命中名称/别名才算 |
| 拼音全拼 | 相等 62 / 开头 52 / 包含 46 | 对中文名与中文别名生成，读音表 `pinyin-table.json`（GB2312 一级汉字+目录用字，每字至多 2 个读音） |
| 拼音首字母 | 相等 48 / 开头 42 / 包含 34 | 多音字按读音集合展开，上限 32 个变体 |
| 部位标签 | 精确 40 / 部分 36 | 肌群/器械/类别代码的中文标签（与客户端 partNames 一致）；查询会先剥离「练、的、肌、部」等填充字。只做单字段匹配，绝不跨字段拼接（`back lever` 仍只命中同名条目，有回归测试锁定） |
| 说明文字 | 15 | 旧行为保留，仅在其它通道全未命中时兜底 |

加权：有完整示范（media-index 中 images>0 或有视频）+6，已收藏 +4。
只影响同通道前后的次序，不会把低通道条目抬到高通道之前太多。

拉丁短词（≤3 字母）防噪：英文名/别名/说明只认整词相等、字段开头、
或某个单词以查询词开头（`dip` ✓ triceps dip），跨词巧合子串不算命中
（`sd` 不会命中 palms down）。中文子串匹配不受此限。

## 俗称词表维护

`SYNONYMS` 只收录「俗称本身不是任何正式名子串」的对子（子串能命中的
不需要词表，如 引体、夹胸、肩推）。新增前先对目录核对：俗称在全部
nameZh+别名里搜不到、扩展词搜得到，才加。当前词表：

虐腹→卷腹/仰卧起坐、箭步→弓步、硬举→硬拉、龙门架→绳索、
拉力器→绳索、单杠→引体向上、推肩→推举、杰克跳→开合跳、
静蹲→靠墙、rdl→romanian deadlift、ohp→overhead press/shoulder press。

「练背、练胸、二头、三头、泡沫轴」这类说法由部位标签通道覆盖，
不需要进俗称表。

## 按部位浏览（人体图）

不知道动作名时走浏览：动作库页有「按部位找动作」人体图（正/背面），
点着色区域即按该肌群筛选，再点一次取消。区域→目录代码的映射在
`client/src/features/gym/media.ts` 的 `regionFilterCodes`，由详情页
着色用的 `muscleGroups` 反演得到，两种口径由
`client/tests/muscle-browser.test.ts` 双向锁定一致；一个区域常对应
多个等价目录代码（如 quadriceps/quads），服务端 `library()` 的
muscle 参数因此支持逗号分隔多值，任一命中即可。

诚实边界：MuscleMap 源图没有背阔肌的独立轮廓（详情页同样不着色），
浏览图不拿其它背部轮廓冒充，改用图下按钮补位并注明；头发、头部、
膝部等没有对应目录肌群的区域不可点。
