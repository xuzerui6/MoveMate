## 候选重挖方法

对固定版本 free-exercise-db（`f00c92c`，Unlicense）做系统性重挖：以名称 token 相似度 + 器械一致性 + 变式冲突词（坐姿/站姿、上斜/下斜、单臂/双臂等）打分，为全部 1,011 条待补 + 141 条图解条目生成候选，共 **419 条有候选**（待补 342、图解 77）。逐条仍须看图核对，不自动采用。

重要发现：2026-10-29 全库审核中的大量「候选已对照」驳回，针对的是 Gym Visual 候选而非本库实拍。例如 exdb:1316 曾因「候选使用曲杠」驳回，而 free-exercise-db 实拍为直杠铃、与条目一致，本批据实采用并在 reviewReason 中注明。每条候选仍按本批标准独立核对，历史上针对本库实拍本身的驳回（如 exdb:0296 握铃数量）继续有效。

**双帧标准（本批明确）**：实拍双帧 = 起始位 + 关键位；交替类动作以所示一侧为代表（另一侧镜像），并须在条目文字中注明交替。此标准与既有 177 张实拍的发布形态一致。
