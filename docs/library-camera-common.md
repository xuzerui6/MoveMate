# 常用动作库摄像头扩展 · 2026-10-31

本批优先动作库、计划和自由训练。增加六类标准动作、十个精确 ID，摄像头筛选从 20 个增至 30 个。独立 AI 训练仍保留现有十种，不新增奖励类型。

| 能力 | 允许的标准 ID | 拍摄及计数 |
| --- | --- | --- |
| 高脚杯深蹲 | `exdb:1760` | 全身略侧；站立→下蹲→站立 |
| 杠铃背蹲 | `exdb:0043`、`exdb:1436` | 上背持杠，全身略侧；下蹲后站起，不包含前蹲、低杠或跳蹲 |
| 站姿杠铃弯举 | `exdb:0031` | 双肩肘腕髋可见；双臂弯举并放回 |
| 平板卧推 | `exdb:0025`、`exdb:0289` | 平凳双臂杠铃／哑铃；斜侧面全身，伸臂→屈肘下放→推回 |
| 站姿俯身反向飞鸟 | `exdb:0378`、`exdb:0383`、`exdb:2292` | 正面斜侧，俯身双臂垂下→向两侧展开→放回，需可靠世界坐标 |
| 坐姿双手哑铃头上臂屈伸 | `exdb:2188` | 屈膝坐稳、双手握一铃，头上伸臂→脑后屈肘→伸肘 |

所有新能力继续标为「试用」。标准变式通过既有动作资料逐条核对，未按名称关键词授予能力；自定义、导入动作不能授予识别权限。未新增动作 ID、数据库表、素材、付费服务或摄像头布局。

## 识别和兼容

- 高脚杯／背蹲复用现有深蹲计数器，杠铃弯举复用已有双臂弯举计数器；未调整已验证的深蹲、开合跳阈值。
- 卧推检查平躺姿态、双肘屈伸、手位及肩髋脚支撑漂移；不把直立推举当作卧推。反向飞鸟检查俯身与三维侧向展开；前举不计入。头上臂屈伸检查坐姿、头上上臂和双肘屈伸；站姿和胸前弯举不计入。
- 复用五帧平滑、两秒起始校准和阶段滞回。角度按实际视频比例或可靠世界坐标计算；看不清方向时提示调整，不靠降低阈值强行计数。
- 新三类测量沿用幅度 35%、控制 25%、姿态 20%、协调 20% 评分。分数不作为计数门槛，信息不足不生成虚构评分；暂停、刷新、遮挡丢弃半程，完整次数与评分保留。
- 共享元数据为 `server/src/gym/library-recognition.json`，工厂统一选择识别器；不在多个入口复制算法。语音按计划上下文读取正确动作、目标和说明。
- 新六类写入要求 `X-MoveMate-Recognition-Version: 3`；旧独立新六种同时兼容 v2/v3。普通请求与离页保存统一升级为 v3。旧页面尝试启动新能力会被要求刷新。
- 进行中的旧快照不静默升级；重新开始训练读取最新能力。计划仍只有一条 `fitness + timer` 主运动，准备、休息和暂停不计时，摄像头不重复发 XP；手动转换保留次数并取消该组识别评分。

摄像头不验证哑铃重量、握法、凳子／保护装置或器械安全，也不提供脊柱健康判断。卧推及杠铃动作的保护条件由使用者自行确认；无法看清关节或支撑时使用手动记录。
