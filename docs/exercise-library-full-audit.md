## 页面及兼容

- 列表只导入轻量能力索引；打开详情/准备示范后读取该 ID 的带哈希 JSON。去重并发加载、限制内存缓存，迟到结果不切换到另一个动作；失败可独立重试，离线提示明确。
- 公开不可变详情 JSON 和查看过的图片可由原有 Service Worker 缓存；认证接口、音视频及 Range 不加入该缓存。
- `/api/v1/exercises?media=images|video` 在分页前与搜索、肌群、器械、收藏、摄像头条件取交集。旧 `ids` 查询仍保持原上限，前端不再用长 ID 列表筛媒体。

- 资料整理只进入官方目录。自定义/导入动作不能通过重名获得媒体、审核或摄像头权限。没有新增表、识别器、XP 奖励或付费资源。
