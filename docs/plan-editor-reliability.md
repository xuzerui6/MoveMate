# 计划编辑可靠性与手机操作修复 · 2026-10-21

## 修复结果

| 问题 | 当前行为 |
| --- | --- |
| 保存返回覆盖新输入 | 保存确认提交快照；等待期间的新编辑继续保留，提示“提交版本已保存，当前还有新修改”，下次保存使用已确认的新版本号 |
| 重复保存、响应丢失 | 同步锁阻止第二次提交；结果不明确时先读取服务器，确认提交已存在则不再 PUT；未提交重试复用原快照 |
| 版本冲突 | 保留本机草稿；“核对服务器版本”先展示确认框，只有明确选择使用服务器版本才放弃本机编辑 |
| 本机存储已满／不可用 | 编辑保留在内存并显示风险，仍可在线保存；本机清理失败不改变服务器已确认结果 |
| 损坏草稿 | 结构校验后隔离，不进入渲染；仅放弃指定账号的指定草稿，不清理其他账号或训练记录 |
| 手机操作栏过高 | 390px 下常驻“保存计划＋更多”，操作栏不超过 90px；分享、打印、放弃草稿、删除在菜单中，电脑继续显示完整操作 |
| 单位混淆 | 自由训练高抬腿显示“对”，计时显示秒，其他动作显示次；编辑字段和打印内容区分次数／配对 |
| 设置读取失败仍显示加载 | 提供独立重试，停止错误的加载文案；保存设置也保留等待期间的新输入 |
| 设置／周日程的缓存来源不明 | 明确只读缓存与联网读取入口；缓存下禁止保存设置、开始训练、调课、跳过及恢复安排 |

计划及设置分别使用提交快照、编辑修订号和服务器确认状态。设置只提交实际修改字段，避免用旧快照重写无关设置。所有接口和数据库结构沿用原实现。

本批也保护了成长状态的本机摘要缓存：本机缓存写入失败不会把已从服务器读取的成长状态变成加载失败。摄像头识别阈值、电脑摄像头区域、运动计时、XP、装备解锁和组局规则未改变。
