# 稳定性与恢复第三批修复 · 2026-10-25

## 修复内容

| 风险 | 当前行为 |
| --- | --- |
| 设置旧草稿覆盖无关新值 | 内部草稿包含格式版本、服务器基线和编辑值。只恢复相对基线实际修改的字段；服务器的其他更新保留。 |
| 同一设置字段双方修改 | 默认采用服务器值，由用户逐字段勾选本机值；器械、杠铃片按整个字段选择。确认期间锁定下方设置表单，保存前再次读取最新设置。再次变化则重新确认。 |
| 旧格式设置草稿无基线 | 显示候选字段，默认全部不勾选；没有自动整份覆盖。 |
| 旧计划草稿被新编辑覆盖 | 先单独归档原稿，再写当前草稿。提供名称、版本、日程、动作、组目标对照；明确使用服务器版本或将本机稿保存为下一版本。恢复另一份旧稿前先保留当前未保存编辑。 |
| 计划再次版本冲突 | 使用刚核对的服务器版本号提交，继续依赖原有版本校验；失败保留原稿，只有明确放弃或保存确认后才清理选中的存档。 |
| 存储满或损坏草稿 | 原稿未能单独存档时禁止覆盖；当前编辑保留在内存并可在线保存。损坏草稿需要单独明确放弃，服务器保存成功不被本机清理失败误报为失败。 |
| 成长接口阻断独立页面 | 动作库、计划、设置、日程、分析、身体记录、数据管理和计划训练由各自接口加载。成长读取失败不遮挡已确认的训练记录或结果。 |
| 未知运动状态被当作空状态 | 独立摄像头／个人计时入口区分服务器、只读缓存和未知状态；未知时只提供重试和动作库／计划入口，不盲目开始另一项运动。 |
| 断网时存储异常打断停止流程 | 先冻结统计、停止识别和关闭语音，再尝试持久化。写入失败时保留按账号、训练隔离的内存操作，提示勿刷新或关闭。 |
| 原请求尚未确认时最后几次动作丢失 | 原操作保持不可变、原操作 ID 和版本号；另存断网时最后的完整摄像头快照。先读取、核对或重试原请求，再补存同一组新增完整次数及评分，不重写手填负重等无关值。 |
| 恢复时服务器已经切组或结束 | 不把旧快照应用到下一组。保留快照、显示原因，用户可明确放弃未上传快照并使用服务器记录。 |
| 损坏同步记录被当作没有操作 | 初始阻止操作，明确读取服务器后恢复。可读的原操作不会因网络标记损坏被清掉；无法找回的未上传内容有真实提示。 |
| 退出账号后旧异步回调污染新账号 | 清除对应内存恢复对象，使旧对象失效，阻止迟到回调再次写入；账号键和训练键继续隔离。 |

设置接口仍是原有部分更新接口，客户端的保存前核对不是新增服务器原子版本协议。计划和训练继续使用既有版本校验、事务及唯一操作机制。没有新增业务接口、数据库迁移、付费资源；XP、动作阈值、装备、签到、组局和电脑摄像头布局未改动。

## 检查方法与结果

本批以代码检查及内存复现为起点，启动原项目本机服务后补齐浏览器检查。Browser 插件不可用，使用已安装的 Playwright 与独立 Chrome。通过正常登录接口取得现有账号会话，凭据只在内存传递；计划、设置和训练写操作采用浏览器模拟响应，不修改线上个人业务记录。

| 验证 | 结果 |
| --- | --- |
| 前端测试 | 152 项通过，本批新增 13 项草稿、冲突及恢复回归 |
| 仓库模式前端测试 | 152 项通过，不重复计入总数 |
| 后端／Workers | 65／26 项通过，保留事务、并发、账号与唯一结算回归 |
| 自动化总数 | **243 项**，152＋65＋26 |
| 构建 | 前端、本机后端、Cloudflare 前端、Workers 类型检查及正常 bundle 通过；81 个媒体文件校验通过 |
| 设置草稿 | 旧草稿只改用力程度，服务器 lb 保持 lb，实际 PUT 仅包含 effort；旧格式默认不覆盖；同字段连续两次冲突均在 PUT 前要求确认 |
| 计划草稿 | 新编辑及刷新后原稿仍在；冲突对照、再次 409、使用最新版本重试、仅清理已确认存档通过；存储满保留原稿和内存，在线保存可用 |
| 成长接口单独失败 | 动作库、计划、设置、日程、分析、身体记录与数据管理可加载；独立训练处于未知状态时不能开始；计划训练及服务器已确认结果仍显示 |
| 断网＋存储满 | 本机模拟保留 7 次手填完成量；先 GET 再用原 ID／版本重试，结束响应丢失时只确认一次结束，不再发第二次 finish |
| 摄像头恢复 | 明确标注的关键点回放完成至少两次动作；故意延迟较早的 progress，断网后次数停止、流及模型释放；重试保留原 progress ID，另存最后完整次数及评分 |
| 损坏同步记录 | 未核对前无写操作；读取服务器后恢复暂停记录，提示未上传数据可能无法找回 |
| 响应式 | 390、768、1440px 冲突对照、字段选择、结果页无横向溢出；长对照可滚动，确认按钮可达 |
| 浏览器应用异常 | 本机检查没有应用运行时异常；预期故障注入的 HTTP 错误不作为应用崩溃 |

本轮没有真人摄像头质量、BLE、有声语音或无代理网络稳定性的新验收，不用关键点回放代替实拍结果。
